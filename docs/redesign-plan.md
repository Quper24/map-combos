# План обновления Quper Simulator

Обновлено: 2 ноября 2026 года.

## Задача

Переработать существующий сайт в этом проекте: структуру, навигацию,
удобство использования и дизайн. Разрабатывать постепенно, начиная
с согласования плана. Первая версия редизайна реализована локально;
перенос сервера пока не выполнен.

## Согласованные требования

- Дизайн: тёмный графитовый фон, зелёные акценты в соответствии с логотипом,
  светлый текст. Эффекты современные, ненавязчивые, помогающие навигации.
- Приоритеты: скорость, оптимизация, адаптивность и понятная структура
  React-компонентов, CSS и проекта в целом.
- Главная представляет Quper Simulator, сборки, VTC, моды и плагины,
  содержит ссылки на разделы, YouTube, Rutube, VK, Twitch и Telegram.
- Раздел сборок сохраняет существующие возможности: выбор версии игры,
  поиск, теги ETS2 / ATS / Конвой / Наши сервера / Только на Boosty,
  сортировку по дате.
- Сборки и разработки предназначены для ETS2 и ATS.
- У каждой сборки своя страница с важной информацией и порядком карт.
- Порядок карт — изображения top, center, bottom, а не текстовый список.
  В текущем компоненте center имеет общую картинку по умолчанию.
- Видеообзор сборки необязателен, может добавляться после публикации сборки.
- Сборки для старых версий игры сохраняются. При обновлении сборки для
  текущей версии игры предыдущая редакция заменяется, а не архивируется.
- Все сборки и вся информация, уже имеющиеся в проекте на начало
  переработки, должны сохраниться. Разрешено менять формат и структуру
  данных, но не терять описания, поля, ссылки, изображения или возможности.
- VTC Quper Simulator: информация о компании и серверах, ссылки на
  соответствующие сборки, Discord, VTCPanel, VTCBase и Trucky.
- VTCPanel, VTCBase и Trucky пока представлены внешними ссылками.
  Интеграции с API возможны позже.
- Моды и плагины — собственные разработки автора, общий каталог.
- При нажатии на мод или плагин открывается отдельная страница:
  описание, изображения, необязательное видео и несколько ссылок,
  например Steam, TruckyMods и Sharemods.
- Отдельный раздел видео: обзоры сборок и модов, покатушки,
  материалы по другим играм. Ограничение ETS2 / ATS к видео не применяется.
- Карточка видео: превью и выбор площадки YouTube / Rutube поверх него.
- Контент обновляется через файлы проекта: замена изображений и изменение
  данных. Админка отложена; в будущем возможен локальный редактор.
- Планируется перенос с GitHub Pages на существующий Linux-сервер
  с игровыми серверами ETS2. Домен qupersimulator.ru сохраняется.
  Желаемые адреса — без символа #.
- Доступы владелец предоставит, когда они понадобятся. Изменения размещения
  сайта не должны нарушать работу игровых серверов. Если понадобится
  перезагрузка или остановка игр, сначала согласовать время с владельцем:
  он предупредит игроков. Допустимость перезагрузки не означает разрешения
  выполнять её без согласования времени.

## Исходная реализация до переработки

- React 19, Vite, React Router, HashRouter.
- Главная сейчас содержит каталог сборок.
- Данные — JS-модули с объектами в src/data/combos, по версиям 1.57–1.61;
  это не строгий JSON. Изображения и профили находятся в public.
- Страницы сборок имеют адрес /#/идентификатор.
- Есть отдельная инструкция /#/server-guide и автоматическая расстановка
  модификаций в профиле.
- Обзор показывается условно, если у сборки заполнено поле video.
- Статистика серверов в Home закомментирована и сейчас не работает.
- Материалы для новых разделов сохранены в content/: описание VTC и три
  ссылки, первая разработка Realistic Economy ETS2 by Quper, четыре видео
  с YouTube и Rutube. Обложка и превью сохранены в public/img/mods и
  public/img/videos. Данные подключены к новому интерфейсу.
- Первые три ролика связаны с существующими сборками 1.61 по
  совпадению YouTube id. Cargo Control — самостоятельное видео, без
  вымышленной страницы разработки и без привязки к Realistic Economy.

## Решения для первой локальной версии

- Разделы: /, /combos, /combos/:id, /vtc, /mods, /mods/:id, /videos.
- Сохранить работу прежних ссылок через совместимость со старыми hash-адресами.
- В общей шапке показывать разделы, а выбор версии игры перенести в каталог.
- Централизованный каталог видео в JSON: id, название, дата, превью,
  игра/категория и ссылки на доступные площадки.
- Сборки и разработки ссылаются на видео по id, чтобы не дублировать ссылки.
  Отсутствующие видео и площадки не создают пустых блоков или кнопок.
- Отдельные файлы данных для сборок, разработок, видео, VTC и общих ссылок;
  инструкцию по обновлению описать в проекте.
- Для адресов без # заменить HashRouter на BrowserRouter и настроить
  веб-сервер для прямого открытия внутренних страниц.
- Архитектура и критерии качества описаны в architecture-proposal.md;
  это предложение для следующего этапа, не уже выполненный рефакторинг.

## Выполнено локально

- BrowserRouter подключён, адреса без # и прежние hash-ссылки работают.
- Все 50 записей перенесены в content/combos/*.json. Контрольные суммы
  подтвердили сохранность каждого поля исходных данных.
- Главная, каталог и страницы сборок, VTC, разработки и видео реализованы.
- Общая зелёная палитра, адаптивная навигация, локальные CSS Modules.
- Перед сборкой проверяются JSON, картинки и связи материалов.
- Добавлены все предоставленные социальные ссылки и Discord.
- Перенос на Linux и проверка серверного декодирования профилей впереди.

## Уточнения после первого просмотра

- Сборки карт — главное направление сайта: прямые названия разделов,
  акцент на ETS2 / ATS в первом экране и визуально выделенная карточка сборок.
- «Больше дорог», «Больше возможностей» и «Больше, чем рейсы» используются
  как подзаголовки; названия разделов — «Сборки карт», «Моды и плагины», «Наша VTC».
- Превью главной показывается полностью, без обрезки и наложения плашки
  версии на изображение. Карточки направлений имеют рамки со всех сторон.
- Boosty — важный источник дохода: отдельный тёплый акцент в шапке,
  первом экране, баннере после сборок, метках и ссылке скачивания архива.
- Инструкция перед загрузкой профиля выделяется самостоятельным блоком
  с заметной кнопкой и напоминанием о резервной копии.
- Проверены ширины 840 и 390 px: горизонтального переполнения нет;
  окно инструкции открывается, закрывается Escape и возвращает фокус.

## Дополнение контента

### Каталог разработок

- Добавлены Cargo Control ETS2 0.6.1, Russian Map Localizer Mega,
  Realistic Russia Economy, Realistic Economy ATS, Remover Ferries и
  Realistic FOV Mirror. Вместе с существующей экономикой ETS2 — 7 записей.
- Cargo Control показывается первым через поле order в JSON, использует
  присланную обложку и связан с обзором на YouTube / Rutube.
- Управление и установка Cargo Control описаны по README-public-0.6.1.md
  проекта плагина: Ctrl+Alt+F9, отдельные клавиши по умолчанию отключены,
  бета для ETS2 1.61.1.9 / Windows x64 / DirectX 11.
- Важное примечание объясняет отличие клавиш на старом превью и в видео.
- Все предоставленные ссылки сохранены; к экономике ETS2 добавлен Sharemods.

### Перенос видео с канала

- Публичная вкладка YouTube «Видео», начиная с обзора Mega Map Combo
  22 сентября 2026 года: всего 13 роликов, добавлено 9 новых.
- Категории: сборки, моды и плагины, покатушки, инструкции, другие игры.
- Для 7 роликов есть Rutube, в том числе сохранена предоставленная
  владельцем ссылка на Cargo Control с параметром доступа.
- Заголовки и точные даты взяты из публичных метаданных YouTube,
  даты отображаются в московском часовом поясе. Новые видео идут первыми.
- Общий обзор VTCBase доступен в фильтрах ETS2 и ATS.
- Новое видео Gold / Big Russia связано с обеими сборками 1.61.
- Реестр: video-import-2026-11-02.json. Все прежние идентификаторы
  и связи четырёх уже добавленных роликов сохранены.

### Серверы VTC и Boosty

- Четыре сервера: два ETS2 и два ATS. Имена и сессии хранятся в servers.json,
  используются на странице VTC и в гайде, копируются кнопками.
- Оба ETS2 используют ETS2 CONVOY MAIN COMBO (ets2-server-map-161), оба ATS —
  ATS CONVOY COMBO (ats-server-map-161). Для обеих игр есть прямые ссылки.
- Поле boosty в JSON содержит пост конкретной сборки; table остаётся отдельной
  ссылкой на таблицу и может отсутствовать. Новая кнопка «Сборка на Boosty»
  располагается выше кнопки «Все сборки на [версия] на Boosty».
  Общие посты версий 1.59–1.61 задаются через boostyUrl в versions.json;
  для более старых версий общая кнопка скрыта.
- На широком экране порядок карт прокручивается отдельно и остаётся рядом
  с инструкцией. На мобильном используется обычная прокрутка страницы.

### Уточнения интерфейса и инструкции

- Окно авторасстановки оформлено в палитре сайта и разделено на подготовку,
  действия на сайте и возвращение в игру. Показывает папку текущей игры,
  напоминает о копии профиля и установке самих модов. Названия действий
  совпадают с инструментом; на серверных сборках поясняются опциональные моды.
- Ссылка на серверный гайд стала отдельным зелёным блоком с крупной кнопкой.
- В благодарности добавлены AlfachLTU (Эдгар) и Genanadii (Гена), с описанием
  помощи в подборе модов, разработке и тестировании.

## Предлагаемая последовательность

1. Согласовать структуру данных и визуальное направление.
2. Сделать общую навигацию и главную, выделить существующий каталог сборок.
3. Переработать страницу сборки с сохранением действующих возможностей.
4. Добавить каталог и страницы разработок, раздел видео и страницу VTC.
5. Проверить мобильную версию, ссылки, фильтры и процесс обновления контента.
6. После подготовки сервера перенести сайт и проверить новые и старые адреса.
