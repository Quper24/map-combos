# Проверка первой версии редизайна

Дата: 2 ноября 2026 года. Изменения локальные, сайт на Linux не размещался.

## Автоматические проверки

- `npm run check:migration` — прошла. Все поля 50 исходных сборок сохранены;
  сверены SHA-256 исходных записей и перенесённых JSON.
- `npm run check:content` — прошла: 50 сборок, 1 разработка, 4 видео,
  изображения, URL, идентификаторы, связи и метаданные версий.
- `npm run format:check` — прошла.
- `git diff --check` — прошла.
- `npm run build` — прошла; подготовлены dist/index.html и dist/404.html.

## Дополнение: серверы VTC и ссылки Boosty

- В `content/servers.json` внесены четыре сервера с полными именами и сессиями,
  предоставленными владельцем. Имена и идентификаторы копируются отдельными
  кнопками; в браузере проверены все четыре сессии без потери цифр.
- VTC и гайд используют общий компонент и один JSON. ETS2 связан с
  `ets2-server-map-161`, ATS — с `ats-server-map-161`. Обе игры имеют по два
  сервера и одну общую серверную сборку для своей игры.
- В гайде обновлены шаги поиска по сессии, ссылки на обе сборки и прежние
  названия серверов. Старый адрес `/#/server-guide` переходит на `/server-guide`.
  Правила, настройки и прежние видеоинструкции сохранены. Поиск по идентификатору
  сверялся с документацией SCS:
  https://modding.scssoft.com/wiki/Documentation/Tools/Dedicated_Server
- Поле `boosty` проверяется вместе с остальными URL. Кнопка «Сборка на Boosty»
  открывает пост из конкретной записи и находится после готового профиля, выше общей кнопки
  «Все сборки на [версия] на Boosty». Общие посты 1.59–1.61 берутся из
  `versions.json`; для 1.57–1.58 общая кнопка скрыта.
  В каталоге также добавлена ссылка на пост конкретной сборки.
  При отсутствии `table` нет ни кнопки таблицы, ни пояснения о ней.
- В браузере проверены общие ссылки Boosty для 1.59, 1.60 и 1.61: каждая
  открывает указанный владельцем пост своей версии. Для 1.57 и 1.58 общей
  кнопки нет. Порядок ссылок: таблица → профиль → пост сборки → все сборки версии.
- На широком экране порядок карт ограничен высотой окна, имеет собственную
  вертикальную прокрутку и остаётся рядом с инструкцией при прокрутке страницы.
  Блок доступен с клавиатуры: PageDown изменяет его scrollTop. На телефоне
  сохраняется обычная прокрутка всей страницы.
- На ширине 390 px у VTC, гайда и ATS-сборки горизонтального переполнения нет.
- Сборка, проверка контента, форматирование и три существующих теста проходят.
  Владелец отдельно обновил JSON сборок 1.61 (поле Boosty, перенос ссылок из
  table, название ATS-сборки). Эти согласованные изменения закономерно отличаются
  от исходного снимка `check:migration`; сам снимок не переписан.

## Дополнение: инструкция профиля и серверный гайд

- Инструкция авторасстановки разбита на три этапа и восемь шагов. Названия
  кнопок и статусов сверены с реализацией. Указаны резервная копия, лимит
  300 КБ, Steam Cloud, точное имя profile.sii и проверка отсутствующих модов.
- Папка профиля выбирается по игре сборки; опциональные моды поясняются
  только при наличии соответствующей настройки. Расшифровка по-прежнему
  внешняя; утверждение о мгновенном удалении файла с сервера убрано,
  поскольку в этом репозитории нет реализации хранения и удаления файлов API.
- Стили окна вынесены в CSS Module с токенами сайта. Окно находится в portal,
  фон не прокручивается, заголовок и кнопка закрытия остаются доступны.
- В браузере проверены открытие, закрытие Escape, переход Tab / Shift+Tab
  между концами окна и возврат фокуса на кнопку открытия. После закрытия
  прокрутка страницы восстанавливается.
- На ширине 390 px окно помещается в экран, горизонтального переполнения
  нет. ATS показывает папку American Truck Simulator и опцию
  «Основные + опциональные»; ETS2 — Euro Truck Simulator 2 и «Карты + Моды».
- Ссылка на гайд оформлена отдельным зелёным блоком с кнопкой. Переход
  открывает /server-guide; подписи ссылок на сборки исправлены на
  ETS2 CONVOY MAIN COMBO и ATS CONVOY COMBO.
- В благодарности добавлены AlfachLTU (Эдгар) и Genanadii (Гена),
  прежняя благодарность Werwolf сохранена. Текст проверен на странице гайда.
- Производственная сборка и проверка контента прошли. Реальные профили
  не загружались, внешний API расшифровки не вызывался.
