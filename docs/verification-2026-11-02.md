# Проверка первой версии редизайна

Дата: 2 ноября 2026 года. Изменения локальные, сайт на Linux не размещался.

## Автоматические проверки

- `npm run check:migration` — прошла. Все поля 50 исходных сборок сохранены;
  сверены SHA-256 исходных записей и перенесённых JSON.
- `npm run check:content` — прошла: 50 сборок, 1 разработка, 4 видео,
  изображения, URL, идентификаторы, связи и метаданные версий.
- `npm run format:check` — прошла.
- `git diff --check` — прошла.
- `npm run build` — прошла; подготовлены dist/index.html и dist/404.html.

## Проверка в браузере

Проверены локальный Vite и производственная сборка через Vite preview.

- Главная, каталог, VTC, моды, отдельный мод, видео и инструкция серверов.
- Каталог 1.57: 9 сборок; поиск quper: 2; тег ATS: 2.
- Каталог 1.61: 11 сборок; тег ATS: 3.
- Добавление/удаление избранного и фильтрация по избранному.
- Поиск сохраняет фокус ввода; фильтры записываются в адрес страницы.
- Старый адрес /#/quper-map-161 открывает /combos/quper-map-161.
- У сборки сохранён порядок top → общий center → bottom.
- При отсутствии обзора у серверной сборки блок обзора не появляется.
- До нажатия на воспроизведение iframe не создаются.
- Окно инструкции профиля открывается и закрывается Escape.
- Страница Realistic Economy содержит обе предоставленные ссылки.
- Каталог разработок обрабатывает пустую категорию плагинов.
- Видеокаталог: 4 ролика; категория модов: Cargo Control; покатушки: пустое
  состояние. Параметр доступа p в ссылке Rutube сохранён.
- Мобильный размер 390×844: главная, меню, VTC и серверная сборка;
  горизонтального переполнения на проверенных страницах нет.
- CSS серверной инструкции не меняет заголовки главной после перехода.
- Производственная страница сборки 1.60 показывает архивную пометку
  и исходный обзор YT2OjGcQW68, а не новый ролик 1.61.

Новые YouTube-ссылки сверены через YouTube oEmbed: автор Quper Simulator,
названия относятся к ETS2 1.61. Обе страницы Rutube также подтверждают 1.61.

## Границы проверки

- Внешний API декодирования профиля не вызывался, реальные файлы профилей
  не загружались. Его работоспособность нужно проверить отдельно перед
  размещением; существующая логика сохранена.
- Воспроизведение роликов на внешних площадках не проверялось до конца.
- Nginx, DNS, HTTPS и игровые службы не изменялись.
- Числовые оценки Lighthouse и полевые метрики скорости не измерялись.
- TypeScript и автоматическая публикация на Linux пока не подключены.
