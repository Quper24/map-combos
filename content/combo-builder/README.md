# Конструктор сборок

Локальный редактор доступен после `npm run dev` по адресу
`/combos/builder/editor`. Черновик сохраняется в браузере и может быть выгружен
в JSON. Для публикации выгрузи проверенный каталог и положи его в эту папку
под именем `ets2-1.62.json` или `ats-1.62.json` для соответствующей версии.
Страница `/combos/builder` подхватывает опубликованные каталоги при сборке сайта.

Новый черновик открывается для ATS 1.62. Чтобы перенести готовую сборку,
нажми «Загрузить шаблон» и выбери её `profile.sii` или TXT с блоком
`active_mods`. Редактор сам расшифрует профиль в браузере и покажет
список файлов перед импортом. JSON можно скачать из редактора после заполнения.

- Общий порядок хранится в порядке индексов `active_mods`. В редакторе, на сайте
  и в PNG приоритет показан сверху вниз, как в менеджере модов.
- Один элемент каталога может включать несколько файлов. Ссылка и картинка
  элемента используются для его файлов, если для файла задано только имя.
  Для отдельных файлов можно указать собственные ссылку и картинку. Картинки
  размещаются в `public/img` и указываются путями `/img/…`.
- Карты и моды доступны для выбора. Фиксы и коннекторы подключаются при наличии
  всех заданных зависимостей. Разные варианты карты используют одно семейство
  и разные обозначения варианта. Зависимости указывают на конкретный вариант.
- Для готового пресета укажи состав и ссылку на пост Boosty. Серверные комплекты
  добавляй через существующий каталог сборок с отдельной страницей и одной
  ссылкой на полный комплект в поле `boosty`.
- Русские названия и пояснения для публичного каталога добавляй в словарь
  `src/i18n/en.json` по правилам сайта.

После добавления каталога запусти `npm run check:content` и `npm test`.
