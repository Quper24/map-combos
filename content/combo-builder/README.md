# Конструктор сборок

Запусти `npm run editor`. Команда открывает Chrome на
`http://127.0.0.1:5179/combos/builder/editor`. Если Chrome установлен в другом
месте, укажи путь к нему в переменной `CHROME_PATH` или открой адрес вручную.
Черновик сохраняется в браузере и может быть выгружен в один JSON. Для публикации
сохрани общий каталог и отдельный JSON каждой готовой сборки.

- «Выгрузить общий каталог» создаёт, например, `ats-1.62.json`. Он хранит
  общие карты, моды, зависимости и порядок. Положи его в эту папку.
- «Выгрузить сборку JSON» в записи сборки создаёт, например,
  `ats-quper-map-1.62.json` или `ats-quper-mods-1.62.json`. Положи его в
  `content/combo-builder/presets`. Короткое имя, например `quper-map`, можно
  указать в форме сборки. Игра и версия добавляются автоматически.

В «Открыть сохранённый JSON» можно выбрать общий каталог вместе с файлами
сборок или открыть их по очереди, начиная с общего каталога. Один файл
черновика тоже можно открыть.
При сборке сайта каждый опубликованный пресет получает карточку в «Сборках
карт». Адрес состоит из игры, короткого имени файла и версии без точки,
например `/ats-quper-map-162`. Прежние ссылки по идентификатору открывают
новый адрес. Версия 1.61 и старше остаётся в архиве.
В режиме редактора сборка без файла в проекте видна в локальном каталоге
с отметкой «Черновик». Если файл уже добавлен, каталог показывает версию из
JSON. Правки черновика доступны в предпросмотре в редакторе.

Перед импортом выбери игру и версию в разделе «Каталог» и нажми «Открыть
каталог». Черновики сохраняются отдельно для каждой пары игра–версия. Если
для выбранной пары ещё нет ни черновика, ни каталога в проекте, откроется
пустой каталог. Затем нажми «Загрузить шаблон» и выбери `profile.sii` или TXT с блоком
`active_mods`. Редактор сам расшифрует профиль в браузере и покажет
список файлов перед импортом. В разделе «Файлы без привязки» отметь все части
одной карты или мода и заполни новую запись. Для обновления импортируй новый
профиль и выбери замену в существующей записи. Новый файл займёт место старого,
а запись сохранит привязку к пресетам и зависимостям.

- Общий порядок хранится в порядке индексов `active_mods`. В редакторе, на сайте
  и в PNG приоритет показан сверху вниз, как в менеджере модов. На сайте и в PNG
  позиции с отметкой «Платная» помечены в порядке загрузки.
- Один элемент каталога может включать несколько файлов. Общую ссылку
  и обложку для карточки укажи один раз. Отметь все части в «Файлы позиции»,
  затем в «Картинки и настройки отдельных файлов» добавь картинку каждой части.
  PNG показывает собственные картинки файлов в порядке загрузки. Ссылку на
  отдельный файл можно оставить пустой, тогда используется общая ссылка.
  Редактор сохраняет картинки в `public/img/combo-builder`. При публикации
  добавь их в Git вместе с JSON.
- Поля `addedAt` и `updatedAt` хранят даты в формате `YYYY-MM-DD`. Редактор
  проставляет дату добавления новой записи и дату при замене файла или
  сохранении обновления. `NEW` и `UPDATE` показываются пять календарных дней
  по Москве, включая дату события. При совпадении дат показывается `NEW`.
  Более поздняя дата обновления даёт `UPDATE` на пять дней с даты обновления.
- Карты и моды доступны для выбора. Фиксы и коннекторы подключаются при наличии
  всех обязательных зависимостей. Если указан список альтернативных
  зависимостей, из него дополнительно нужна хотя бы одна запись. Разные варианты карты используют одно семейство
  и разные обозначения варианта. Зависимости указывают на конкретный вариант.
- Для общего мода или фикса включи «Подключать при выборе любой карты».
  Такая запись скрыта из выбора и добавляется в общий порядок автоматически.
  В JSON это `autoWithMaps: true`. Режим заменяет список зависимостей,
  а из готовых пресетов убирается ручная отметка этой записи.
- Для общей библиотеки файлов выбери тип «Пакет ресурсов». Укажи её в
  обязательных зависимостях каждой карты, которой она нужна. Пакет добавится
  один раз при выборе любой из этих карт. В записи пакета список «Что требуется
  самому пакету» предназначен для его собственных зависимостей.
- В «Готовых сборках» укажи состав, готовый профиль, пост Boosty и теги.
  Игра и версия игры берутся из каталога. Версию сборки, например `1.2`,
  можно указать отдельно. Она отображается на карточке и странице сборки.
  Перед выгрузкой обновления укажи новый номер в поле «Версия сборки».
  «Выгрузить сборку JSON» добавит в этот файл выпуск с датой и составом,
  включая автоматически подключённые позиции. На странице сборки появится
  история с добавленными и удалёнными модами и изменениями версий. Повторная
  выгрузка с тем же номером сохраняет запись прежнего выпуска.
  Можно загрузить обложку для карточки и добавить ссылку на видеообзор.
  На странице обычной сборки посетитель
  может подключать и отключать карты и моды, а порядок пересчитывается.
  Если вместе с выбранной картой отключатся зависимые карты или моды,
  кнопка «Отключить» показывает предупреждение с их названиями.
  Кнопка «Поделиться сборкой» создаёт ссылку с игрой, версией и выбранными
  позициями. При открытии ссылки конструктор заново подбирает зависимости.
  Для серверной сборки отметь «Наши сервера»: состав фиксирован, комплект
  доступен на Boosty.
- Русские названия и пояснения для публичного каталога добавляй в словарь
  `src/i18n/en.json` по правилам сайта.

После добавления каталога запусти `npm run check:content` и `npm test`.
