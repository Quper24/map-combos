# Контент новой версии сайта

Здесь хранятся данные сайта. Все 50 существующих сборок перенесены из
JS-модулей в combos/*.json с проверкой каждого поля. Данные подключены
к новому интерфейсу. Изображения и файлы профилей сохранили свои пути.

## Файлы

- vtc.json — описание компании и внешние ссылки.
- mods/*.json — один мод или плагин в каждом файле.
- videos.json — общий каталог видео.
- combos/v1.XX.json — сборки соответствующей версии игры.
- site.json — социальные ссылки и currentGameVersion, актуальная версия игры.
- versions.json — подписи и сведения о версиях игры.

После редактирования запустите `npm run check:content`. Перед публикацией —
`npm run build`. Форматировать файлы можно командой `npm run format`.

## Сборки

Для обновления замените нужные картинки и измените существующую запись:
номер сборки version, дату date (ДД.ММ.ГГ), ссылки и другие поля.
Идентификатор id лучше сохранять: на него ведут опубликованные ссылки.
Старую редакцию сборки для той же версии игры сохранять отдельно не нужно.
Файлы для старых версий игры не удаляйте.

Поля image_top, image_center и image_bottom содержат пути к картинкам
порядка модов. Если image_center отсутствует, используется общая картинка
/img/combos/center.jpg. Поле video — необязательный YouTube ID старого формата;
чтобы добавить также Rutube, создайте запись в videos.json и свяжите её
с нужными сборками через relatedComboIds.

При добавлении новой версии игры создайте файл combos/v1.XX.json и добавьте
метаданные в versions.json. Файл сборок обнаружится автоматически.
Затем обновите currentGameVersion в site.json. Главная и VTC подхватят
соответствующий файл автоматически. В метаданных должна быть одна текущая
версия; прежнюю отметьте как legacy.

Используется строгий JSON: без комментариев и запятых после последнего
элемента. Названия полей предназначены для кода, тексты можно редактировать.

## Разработки

У записи есть уникальный id, type (mod или plugin), title, games,
краткое summary, абзацы description, список features, cover и ссылки links.
Поле images содержит дополнительные изображения, videoIds — ссылки на
записи каталога видео. Пустые списки допустимы и не создают пустых блоков
в интерфейсе. Локальные картинки лежат в public/img/mods.

Описание Realistic Economy составлено по авторским страницам TruckyMods
и Steam, указанным в links. Изображение предоставлено владельцем проекта:
https://storage.truckymods.io/projects/realistic-economy-ferry-by-quper/media/6c4080de8a60889dfb4ab82b4b960211.webp

Версия мода и совместимые версии игры пока не заданы: не следует выдавать
номер выпуска на одной площадке за общую актуальную версию обеих площадок.
Видео Cargo Control не относится к Realistic Economy, поэтому к этой
разработке оно не привязано.

## Видео

- id — постоянный уникальный идентификатор.
- title — название ролика.
- game — идентификатор игры; не ограничен ETS2 и ATS.
- category — combos, mods, drives, guides или games.
- thumbnail — путь к картинке в public, начиная с /img/.
- platforms — ссылки на доступные площадки youtube и/или rutube.
- relatedComboIds и relatedModIds — связи с материалами сайта.

Достаточно одной площадки. Дату публикации можно будет добавить отдельно,
когда она известна; дата внесения записи не считается датой выхода видео.
Для собственного превью замените файл или поменяйте thumbnail.

Один ролик может относиться к нескольким сборкам. Первые три ролика связаны
с записями версии 1.61 по совпадающему YouTube id. Они не переносятся
автоматически на новые версии игры или на будущие обновления сборки.

Полные URL сохраняются без удаления параметров: в частности,
параметр p у ссылки Rutube для Cargo Control необходим для доступа по ссылке.
