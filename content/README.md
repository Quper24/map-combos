# Контент новой версии сайта

Здесь хранятся данные сайта. Все 50 существующих сборок перенесены из
JS-модулей в combos/*.json с проверкой каждого поля. Данные подключены
к новому интерфейсу. Изображения и файлы профилей сохранили свои пути.

## Файлы

- vtc.json — описание компании и внешние ссылки.
- servers.json — серверы ETS2 / ATS, имена, сессии и ссылка на серверную сборку.
- mods/*.json — один мод или плагин в каждом файле.
- videos.json — общий каталог видео.
- combos/v1.XX.json — сборки соответствующей версии игры.
- site.json — социальные ссылки и currentGameVersion, актуальная версия игры.
- versions.json — подписи и сведения о версиях игры.

После редактирования запустите `npm run check:content`. Перед публикацией —
`npm run build`. Форматировать файлы можно командой `npm run format`.

## Сборки

Для обновления замените нужные картинки и измените существующую запись:
номер сборки version, дату date (ДД.ММ.ГГ), ссылки и другие поля.
Идентификатор id лучше сохранять: на него ведут опубликованные ссылки.
Старую редакцию сборки для той же версии игры сохранять отдельно не нужно.
Файлы для старых версий игры не удаляйте.

Поля image_top, image_center и image_bottom содержат пути к картинкам
порядка модов. Если image_center отсутствует, используется общая картинка
/img/combos/center.jpg. Поле video — необязательный YouTube ID старого формата;
чтобы добавить также Rutube, создайте запись в videos.json и свяжите её
с нужными сборками через relatedComboIds.

Ссылки задаются отдельно: table — таблица файлов, boosty — пост конкретной
сборки на Boosty, profile — готовый профиль. Все три поля необязательные.
Если table отсутствует, кнопка таблицы и текст о ней не выводятся.
Поле boosty добавляет кнопку «Сборка на Boosty» в карточке каталога
и на странице сборки. Эта кнопка находится сразу после готового профиля, выше кнопки
«Все сборки на 1.61 на Boosty», где номер берётся из версии игры сборки.
Общая ссылка для каждой версии задаётся полем boostyUrl в versions.json.
Сейчас она заполнена для 1.59, 1.60 и 1.61. Без boostyUrl общая кнопка
не показывается, в том числе для 1.57 и 1.58.
Исторические ссылки Boosty в поле table сохраняют работу
и подписываются как материалы на Boosty.

При добавлении новой версии игры создайте файл combos/v1.XX.json и добавьте
метаданные в versions.json. Файл сборок обнаружится автоматически.
Затем обновите currentGameVersion в site.json. Главная подхватит
соответствующий файл автоматически. Связи серверов обновляются в servers.json.
В метаданных должна быть одна текущая
версия; прежнюю отметьте как legacy.

Используется строгий JSON: без комментариев и запятых после последнего
элемента. Названия полей предназначены для кода, тексты можно редактировать.

## Серверы VTC

Имена и сессии обновляются в servers.json. Страница VTC и гайд используют
одни данные. Каждый блок игры содержит game, title, servers и необязательную
ссылку combo (id сборки и label для отображения). Оба сервера ETS2 связаны
с ets2-server-map-161 под названием ETS2 CONVOY MAIN COMBO, оба сервера ATS —
с ats-server-map-161 под названием ATS CONVOY COMBO.

У сервера есть постоянный id, полное name и sessionId. Сессию храните строкой
в кавычках целиком, включая / и цифры после неё: числовое значение такой длины
может потерять точность в JavaScript. При смене версии серверной сборки
обновите combo.id.

Кнопки копируют имя или сессию целиком. Если браузер запрещает доступ к буферу,
можно выделить текст и скопировать его вручную. Наличие карточки не означает
автоматическую проверку доступности сервера.

## Разработки

У записи есть уникальный id, type (mod или plugin), title, games,
краткое summary, абзацы description, список features, cover и ссылки links.
Поле images содержит дополнительные изображения, videoIds — ссылки на
записи каталога видео. Пустые списки допустимы и не создают пустых блоков
в интерфейсе. Локальные картинки лежат в public/img/mods.

Поле order задаёт порядок в каталоге: меньшее число показывается раньше.
Cargo Control имеет order: 0. Без этого поля используется 1000; при равенстве
записи сортируются по названию. Поля version, gameVersions, notice и
installation необязательные: версия, совместимость, важное примечание и шаги
установки. Дополнительные изображения можно задавать объектами src / alt.

Описание Realistic Economy составлено по авторским страницам TruckyMods
и Steam, указанным в links. Изображение предоставлено владельцем проекта:
https://storage.truckymods.io/projects/realistic-economy-ferry-by-quper/media/6c4080de8a60889dfb4ab82b4b960211.webp

Версия мода и совместимые версии игры пока не заданы: не следует выдавать
номер выпуска на одной площадке за общую актуальную версию обеих площадок.
Видео Cargo Control связано со страницей cargo-control. Управление
версии 0.6.1 описано по публичной инструкции проекта плагина; на обложке и
в ролике показано прежнее управление, что отмечено в notice.

## Видео

- id — постоянный уникальный идентификатор.
- title — название ролика.
- game — идентификатор игры; не ограничен ETS2 и ATS.
- games — необязательный список игр для общих роликов, например ["ets2", "ats"].
- publishedAt — дата публикации на YouTube в ISO 8601, например
  "2026-11-01T16:13:12.000Z". Сортировка учитывает время, отображение — московский часовой пояс.
- category — combos, mods, drives, guides или games.
- thumbnail — путь к картинке в public, начиная с /img/.
- platforms — ссылки на доступные площадки youtube и/или rutube.
- relatedComboIds и relatedModIds — связи с материалами сайта.

Достаточно одной площадки. Неизвестную дату публикации можно не указывать:
такие ролики показываются после датированных. Дата внесения записи не считается
датой выхода видео. По умолчанию новые ролики идут первыми; в каталоге есть
переключатель обратного порядка. На главной показываются три самых новых видео.
Для собственного превью замените файл или поменяйте thumbnail.

Один ролик может относиться к нескольким сборкам. Обзоры Mega, Quper,
Gold / Big Russia и Best Mods связаны с записями версии 1.61 по совпадающему
YouTube id. Они не переносятся
автоматически на новые версии игры или на будущие обновления сборки.

Полные URL сохраняются без удаления параметров: в частности,
параметр p у ссылки Rutube для Cargo Control необходим для доступа по ссылке.

2 ноября 2026 года каталог дополнен публичными роликами вкладки «Видео»
канала Quper Simulator начиная с 22 сентября 2026 года. Shorts и архивы
трансляций в этот перенос не включались. Реестр проверки:
docs/video-import-2026-11-02.json. В каталоге 13 видео, у 7 есть ссылка Rutube,
включая ранее предоставленную владельцем ссылку на Cargo Control.
